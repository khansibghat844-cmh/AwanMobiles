PUBLISH WITH NETLIFY (SIMPLE OPTION)
1. Extract the ZIP file on your computer so you can see the `awan_mobiles_site` folder and `index.html` inside it.
2. Create/sign in to a Netlify account: https://app.netlify.com/
3. Open https://app.netlify.com/drop
4. Drag the extracted `awan_mobiles_site` folder (not the ZIP file) into the drop area.
5. Netlify will publish the site and show you a public address ending in `netlify.app`. Open it on your phone to test it, then share the link with customers.
6. To update the site later, edit `index.html`, then upload the updated folder again using the site's deploy page.

CUSTOM DOMAIN (OPTIONAL)
1. Buy a domain from a reputable domain registrar. Examples to consider are awanmobiles.pk, awanmobiles.com.pk, or awanmobiles.com, if available. Availability and prices vary; these names are only suggestions.
2. In your hosting dashboard, open the site's domain settings and add the domain you purchased.
3. Follow the host's instructions to update DNS records at the domain registrar. Do not copy random DNS values; use the exact values shown in your hosting account.
4. Wait for DNS changes and HTTPS certificate setup to finish. DNS propagation can take up to 24 hours or sometimes longer.
